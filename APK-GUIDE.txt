======================================================
   ساخت و نصب نسخه اندروید (APK) بازی همیار برق
======================================================

روش اول — خودکار از طریق گیت‌هاب (پیشنهادی، بدون نیاز به اندروید استودیو)
----------------------------------------------------------------------
۱) کل پوشه‌های src و public و فایل‌های جدید را روی گیت‌هاب آپلود و Commit کن:
   - capacitor.config.ts
   - package.json (نسخه جدید با Capacitor)
   - پوشه .github/workflows (فایل build-apk.yml هم داخلش هست)
   - پوشه src و public

۲) بالای صفحه ریپو، تب «Actions» را باز کن.
   یک اکشن به نام «Build Android APK» به‌صورت خودکار اجرا می‌شود (۵ تا ۸ دقیقه).

۳) وقتی تیک سبز خورد:
   - روی همان اجرا کلیک کن
   - پایین صفحه، بخش Artifacts فایل «HamyarBargh-APK» را دانلود کن (فایل zip را باز کن، داخلش hamyar-bargh-bushehr.apk است)
   - یا در صفحه «Releases» نسخه apk-latest همیشه آخرین APK آنجاست.

۴) فایل apk را روی گوشی کپی و نصب کن (بار اول اجازه «نصب از منابع ناشناخته» بده).

هر بار کد جدید آپلود کنی، یک APK تازه خودکار ساخته می‌شود.


روش دوم — روی همین کامپیوتر (اگر اندروید استودیو داری)
-----------------------------------------------------
   npm install
   npm run build
   npx cap add android
   npx cap sync android
   cd android
   gradlew assembleDebug
   فایل خروجی:
   android/app/build/outputs/apk/debug/app-debug.apk


نام پکیج (Package Name): ir.bushehr.bargh.hamyar
عنوان نصب‌شونده روی گوشی: «همیار برق بوشهر»

کنترل‌های موبایل:
- جوی‌استیک سمت چپ: حرکت و دویدن (دکمه را تا انتها بکش = دویدن)
- کشیدن انگشت روی سمت راست صفحه: چرخاندن دوربین
- دکمه سبز بزرگ: تعامل / صحبت / باز کردن در (معادل Enter و E)
- پرش، اسکنر و چتر پرواز: دکمه‌های سمت راست
- ردیف دکمه‌های بالا: نقشه، مأموریت‌ها، فروشگاه، آمار، توقف
